# MacroMatrix — downloads

Android releases of **MacroMatrix**, the food diary with all 69 nutrients, a scanner for additives and allergens, and friends, levels and battles. More info: https://app.divinenet.online

## Install with Obtainium (automatic updates)

1. Install [Obtainium](https://github.com/ImranR98/Obtainium) (also on F-Droid and IzzyOnDroid).
2. Tap **Add app** and paste: `https://github.com/Tanatloc/macromatrix-releases`
3. Tap **Add**, then **Install**. Obtainium checks for new versions and updates the app for you.

Which file? `arm64-v8a` for almost every phone from the last few years; `universal` works everywhere but is larger.

## Install by hand

Download the APK from [Releases](https://github.com/Tanatloc/macromatrix-releases/releases/latest) and open it on your phone.
